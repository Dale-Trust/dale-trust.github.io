# Dale Trust — Website & Tools

The Dale Supporters Trust's site and officer tools. Owned by the Trust's GitHub organisation from birth.

## Structure
- `index.html` — the main site (matchday hub, fixtures, partners, who's who)
- `join.html` — membership sign-up (demo; production wiring via PAY_ENDPOINT)
- `exiles.html` — exile groups, featuring SMAC
- `tools/` — officer tools: `compose.html` (post composer), `coach-poster.html` (+ template), `dashboard.html` (membership analysis — drag the spreadsheet on, nothing uploads)
- `newsletters/` — newsletter templates
- `img/` — `brand/` (Trust marks) · `badges/` (club crests) · `partners/` · `comps/` · `photos/`
- `data/` — fixtures as CSV/JSON

## Deploy
GitHub Pages: Settings → Pages → main branch, root. Favicons stay at root.

## Rules
Keep images in their `img/` subfolders. New credentials to the Bitwarden vault — never in this repo.
